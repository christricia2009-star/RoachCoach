# Roach Coach Radar — Level 27,515

This build consolidates the intelligence architecture around one canonical pipeline:

**Sources → Observations → Evidence Fusion → Confidence → Prediction → Anomaly → Hotspot → Verification/Learning**

## Included
- Canonical `RadarObservation` and `EvidenceItem` models
- Multi-source confidence fusion
- Route/time pattern learning
- Advanced prediction windows
- Anomaly detection
- Hotspot clustering
- What’s Hot briefing
- Replay/simulation engine
- Local AI cost/cache accounting
- Radar Lab UI
- Modern MapKit map content builder APIs
- Time-machine slider on the main map
- Manual provider credentials remain in iOS Keychain via Settings
- Backend observation feed and bounded live scan endpoint

## Data-source policy
The source framework is intentionally modular. Official APIs, public/open datasets, owner feeds, and other authorized sources can be plugged in without changing the intelligence core. The app does not bypass authentication or platform access controls.

## Important
The backend must be deployed and reachable from the iPhone for live external-source collection. The iOS app alone cannot magically query provider APIs without a configured endpoint/source.
